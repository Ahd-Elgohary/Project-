This project demonstrates the design and implementation of a **secure network topology** connecting two branches using **FortiGate firewalls**.
The setup includes:

* **Multiple WAN connections** for internet redundancy.
* **DHCP configuration** to assign IP addresses dynamically to users, servers, and IP phones.
* **VLAN segmentation** for structured traffic management.
* A secure **IPsec VPN tunnel** between branches to allow internal communication.
* Future enhancement with **SD-WAN** for load balancing, failover, and optimized WAN usage.

This documentation provides the **network design, implementation steps, and testing procedures** to ensure secure and reliable branch connectivity.
